## ❌ Проблемы которые были:
1. Система не находила колонку "Посл. закупка" в файле Барыс
2. Ошибка `order_value is not defined` при интеграции цен в анализ складов
3. Система пыталась использовать 6-ю колонку вместо 12-й

## ✅ Исправления которые сделаны:

### 1. Исправлена ошибка `order_value`
**Файл:** `warehouse_price_integration.py`
```python
# БЫЛО:
recommendation += f" (к заказу: {order_value:,.0f} ₸)"

# СТАЛО:
order_cost = order_quantity * price
recommendation += f" (к заказу: {order_cost:,.0f} ₸)"
```

### 2. Улучшен поиск колонки "Посл. закупка"
**Файл:** `warehouse_price_integration.py`

Добавлена **диагностика всех колонок** с расширенным поиском:
```python
# Показывает все колонки для диагностики
st.write("🔍 **Поиск колонки 'Посл. закупка' среди всех колонок:**")

# Расширенный поиск вариантов названий
is_posled_zakupka = any([
    'посл' in col_name_clean and 'закуп' in col_name_clean,
    'последн' in col_name_clean and 'закуп' in col_name_clean,
    col_name_clean == 'посл. закупка',
    'last' in col_name_clean and 'purchase' in col_name_clean,
    col_name_clean.replace(' ', '').replace('.', '') == 'послзакупка'
])
```

### 3. Создан принудительный режим для 12-й колонки
**Файл:** `force_column_12_fix.py`

- **Принудительно** использует 12-ю колонку независимо от названия
- **Агрессивно** очищает данные для извлечения цен
- **Начинает с L4** (4-я строка) как вы указали

### 4. Добавлена диагностика файла
**Файл:** `diagnose_barys_file.py`

- Показывает все колонки с их названиями
- Анализирует данные в 12-й колонке (L)
- Ищет колонки со словами "посл" и "закуп"
