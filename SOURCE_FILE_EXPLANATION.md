# 📄 Объяснение колонки `source_file`

## ❓ Что это за колонка?

Колонка `source_file` - это **служебная колонка**, которая добавляется системой множественных файлов (`integration_patch.py`) для отслеживания источника данных.

## 🔍 Откуда она берется?

### В файле `integration_patch.py`:
```python
# При обработке каждого файла добавляется:
'source_file': filename

# При объединении файлов:
'source_file': lambda x: ', '.join(x.unique())
```

### Цель:
- **Отслеживание** из какого файла взяты данные
- **Объединение** информации при обработке множественных файлов
- **Диагностика** проблем с данными

## ⚠️ Проблема с ценами

Колонка `source_file` **мешает** извлечению цен, потому что:
1. Сдвигает индексы колонок
2. Может попасть в 12-ю позицию вместо реальных цен
3. Содержит текст вместо чисел

## ✅ Решение

В обновленной системе (`warehouse_price_integration.py`):

```python
# Автоматически удаляем служебные колонки перед извлечением цен
columns_to_drop = ['source_file', 'branch', 'processing_timestamp']

for col in columns_to_drop:
    if col in source_data.columns:
        source_data = source_data.drop(columns=[col])
        st.info(f"🧹 Удалена служебная колонка '{col}' из {filename}")
```

## 🔧 Что изменилось

### Раньше:
```
Колонка 1: Наименование
Колонка 2: Категория
...
Колонка 11: source_file  ← служебная колонка
Колонка 12: Посл. закупка ← цены сдвинулись!
```

### Теперь:
```
Колонка 1: Наименование
Колонка 2: Категория
...
Колонка 11: Посл. закупка  ← цены на правильном месте
(source_file удалена)
```

## 🚀 Результат

- ✅ Служебные колонки автоматически удаляются
- ✅ Цены находятся в правильных позициях
- ✅ Система показывает какие колонки удалены
- ✅ Не влияет на функциональность множественных файлов

---

**🎯 Короче:** `source_file` - это техническая колонка для отслеживания файлов, которая теперь автоматически удаляется при извлечении цен, чтобы не мешать поиску ценовых данных.
