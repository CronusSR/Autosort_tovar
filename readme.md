# 📦 Модульная система анализа товарных запасов v3.0

Система для автоматизации анализа товарных запасов с возможностью выбора типа анализа и пошаговой обработки данных.

## 🎯 Основные возможности

### 🔤 ABC Анализ
- Классификация товаров по принципу Парето (80/20)
- Автоматическое присвоение классов A, B, C
- Анализ по категориям товаров
- Парето-диаграммы и визуализации

### 📊 Расчет ADS (Среднедневные продажи)
- Обработка файлов продаж по месяцам
- Автоматический расчет ADS = Продажи / 365 дней
- Выявление топ товаров по продажам
- Подготовка данных для расчета минимальных запасов

### 📋 Расчет минимальных запасов
- Формула: MIN = ADS × (дни запаса + транзитное время)
- Настраиваемые параметры:
  - Транзитное время (IP): по умолчанию 7 дней
  - Дни запаса: по умолчанию 30 дней
- Учет коэффициента безопасности

### ⚖️ Сравнение остатков
- Сопоставление текущих остатков с минимальными запасами
- Выявление товаров с дефицитом
- Определение критичных позиций
- Формирование рекомендаций по заказу

## 📊 Формулы и расчеты

### ADS (Average Daily Sales)
```
ADS = Общие продажи за период / 365 дней
```

### Минимальный запас
```
MIN = ADS × (дни запаса + транзитное время)
```

### Дефицит
```
Дефицит = MIN запас - Текущий остаток
```

### Рекомендуемый заказ
```
Заказ = Дефицит × Коэффициент безопасности
```

### ABC Классификация
- **A товары**: Накопительно до 80% продаж
- **B товары**: Накопительно 80-95% продаж  
- **C товары**: Остальные товары (95-100%)
