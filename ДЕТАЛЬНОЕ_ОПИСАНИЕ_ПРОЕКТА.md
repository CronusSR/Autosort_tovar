## 🏗️ Архитектура и структура проекта

Проект **Autosort_tovar** представляет собой **комплексную систему для анализа и оптимизации товарных запасов** с поддержкой множественных складов и филиалов. Система построена на Python с использованием Streamlit для веб-интерфейса.

### 🎯 Основная цель системы

Автоматизация процесса управления товарными запасами через:
- **Расчет среднедневных продаж (ADS)**
- **ABC анализ по продажам**
- **Расчет оптимальных минимальных и максимальных запасов**
- **Анализ складских остатков**
- **Генерацию рекомендаций по перемещениям товаров**
- **Денежное выражение дефицитов и заказов**

### 🔧 Архитектура системы

#### Основные компоненты:

1. **Ядро системы** (`ModularInventorySystem`) - центральный класс обработки данных
2. **Веб-интерфейс** (`streamlit_modular_app.py`) - главное приложение
3. **Патч интеграции** (`integration_patch.py`) - загрузка множественных файлов
4. **Анализаторы** - специализированные модули для различных типов анализа
5. **UI компоненты** (`modern_ui_components.py`) - современный дизайн

#### Структура взаимодействия:
```
Пользователь → Streamlit UI → ModularInventorySystem → Анализаторы → Результаты
```

## 📊 2. Расчет анализа Парето (ABC)

### Основной ABC анализ

**Файл:** `modular_inventory_system.py` (строки 1060-1208)

```python
def perform_abc_analysis(self) -> Dict:
    """ИСПРАВЛЕННЫЙ ABC анализ без ошибок numpy"""
    
    # 1. Подготовка данных
    df = self.abc_data.copy()
    df['annual_sales'] = pd.to_numeric(df['annual_sales'], errors='coerce').fillna(0)
    
    # 2. Сортировка по убыванию продаж (принцип Парето)
    df = df.sort_values('annual_sales', ascending=False)
    
    # 3. Расчет процентных долей продаж
    total_sales = df[df['annual_sales'] > 0]['annual_sales'].sum()
    
    df['sales_percentage'] = 0.0
    positive_mask = df['annual_sales'] > 0
    df.loc[positive_mask, 'sales_percentage'] = (df.loc[positive_mask, 'annual_sales'] / total_sales) * 100
    
    # 4. Расчет накопительного процента (кумулятивный процент)
    df['cumulative_percentage'] = 0.0
    df.loc[positive_mask, 'cumulative_percentage'] = df.loc[positive_mask, 'sales_percentage'].cumsum()
    df.loc[~positive_mask, 'cumulative_percentage'] = 100.0
    
    # 5. Присвоение ABC классов по границам Парето
    df['abc_class'] = 'C'  # По умолчанию все C
    
    # Присваиваем классы по условиям:
    df.loc[(df['annual_sales'] > 0) & (df['cumulative_percentage'] <= 80), 'abc_class'] = 'A'
    df.loc[(df['annual_sales'] > 0) & (df['cumulative_percentage'] > 80) & (df['cumulative_percentage'] <= 95), 'abc_class'] = 'B'
    # Товары с annual_sales == 0 остаются класса C
```

### Формулы ABC анализа:

1. **Процентная доля продаж:**
   ```
   sales_percentage = (annual_sales_товара / total_sales_всех_товаров) × 100
   ```

2. **Накопительный процент:**
   ```
   cumulative_percentage = CUMSUM(sales_percentage) по убыванию продаж
   ```

3. **Границы ABC классов:**
   - **A класс:** cumulative_percentage ≤ 80% (топ товары дающие 80% продаж)
   - **B класс:** 80% < cumulative_percentage ≤ 95% (товары дающие 15% продаж) 
   - **C класс:** cumulative_percentage > 95% (товары дающие 5% продаж)

### ABC анализ по подкатегориям

**Файл:** `subcategory_abc.py` (строки 176-278)

```python
def perform_subcategory_abc_analysis(self) -> Dict:
    """Выполнение ABC анализа по подкатегориям"""
    
    # Анализ по каждой подкатегории отдельно
    for subcategory in self.abc_data['subcategory'].unique():
        subcategory_data = self.abc_data[self.abc_data['subcategory'] == subcategory].copy()
        
        # 1. Сортируем по продажам внутри подкатегории
        subcategory_data = subcategory_data.sort_values('annual_sales', ascending=False)
        
        # 2. Рассчитываем проценты внутри подкатегории
        total_subcategory_sales = subcategory_data['annual_sales'].sum()
        
        if total_subcategory_sales > 0:
            # Процент от продаж подкатегории
            subcategory_data['sales_percentage'] = (subcategory_data['annual_sales'] / total_subcategory_sales) * 100
            
            # Накопительный процент внутри подкатегории
            subcategory_data['cumulative_percentage'] = subcategory_data['sales_percentage'].cumsum()
            
            # 3. Присваиваем ABC классы внутри подкатегории
            subcategory_data['abc_class'] = subcategory_data['cumulative_percentage'].apply(
                lambda x: 'A' if x <= 80 else 'B' if x <= 95 else 'C'
            )
```

#### Ключевые отличия подкатегорного анализа:

1. **Независимый расчет:** ABC анализ проводится отдельно внутри каждой подкатегории
2. **Локальные проценты:** 100% = сумма продаж только данной подкатегории
3. **Локальная сортировка:** Сортировка по убыванию только внутри подкатегории

```python
def combine_data_safe(system):
    """Безопасное объединение данных"""
    try:
        all_dataframes = []
        processed_results = system.multiple_files_data.get('processed_results', {})
        
        # Сбор всех обработанных DataFrame'ов
        for filename, result in processed_results.items():
            if result.get('success', False) and 'data' in result:
                df = result['data']
                if isinstance(df, pd.DataFrame) and not df.empty:
                    all_dataframes.append(df)
        
        # Объединение через concat
        combined_df = pd.concat(all_dataframes, ignore_index=True)
        initial_count = len(combined_df)
        
        # Функции агрегации для дублирующихся товаров
        agg_funcs = {
            'ads': 'sum',                               # ADS суммируется
            'average_value': 'sum',                     # Средние продажи суммируются
            'total_sales': 'sum',                       # Общие продажи суммируются
            'branch': lambda x: ', '.join(x.unique()), # Филиалы объединяются через запятую
            'source_file': lambda x: ', '.join(x.unique()) # Файлы объединяются
        }
        
        # Обработка цен (если есть)
        if 'last_purchase_price' in combined_df.columns:
            agg_funcs['last_purchase_price'] = 'mean'  # Средняя цена
        
        # Группировка по номенклатуре и агрегация
        combined_df = combined_df.groupby('номенклатура').agg(agg_funcs).reset_index()
```

### Особенности агрегации:
- **ADS суммируется** - товар с продажами в разных филиалах получает суммарный ADS
- **Цены усредняются** - при разных ценах берется среднее арифметическое
- **Филиалы сохраняются** - информация о всех филиалах сохраняется через запятую
- **Дубликаты удаляются** - остается одна запись на товар

```python
def apply_subcategory_autofill_to_df(df, branch_name):
    # Собираем ADS по подкатегориям (только товары с ADS > 0)
    subcategory_ads = {}
    for _, row in df.iterrows():
        if ads_value > 0:
            # Извлекаем подкатегорию (первые 2 слова)
            words = item_name.split()
            subcategory = ' '.join(words[:2]) if len(words) >= 2 else words[0]
            subcategory_ads[subcategory].append(ads_value)
    
    # Рассчитываем средние по подкатегориям
    subcategory_averages = {}
    for subcategory, ads_values in subcategory_ads.items():
        if ads_values:
            subcategory_averages[subcategory] = sum(ads_values) / len(ads_values)
    
    # Заполняем товары с ADS=0
    for idx, row in df.iterrows():
        if ads_value == 0:
            item_name = str(row['номенклатура'])
            words = item_name.split()
            
            # 1. Точная подкатегория
            subcategory = ' '.join(words[:2])
            if subcategory in subcategory_averages:
                df.at[idx, 'ads'] = subcategory_averages[subcategory]
            
            # 2. Первое слово
            elif words and words[0] in subcategory_averages:
                df.at[idx, 'ads'] = subcategory_averages[words[0]]
            
            # 3. Минимальный ADS
            else:
                overall_avg = sum(subcategory_averages.values()) / len(subcategory_averages)
                df.at[idx, 'ads'] = max(0.01, overall_avg * 0.05)
```

### Квантильная классификация важности

**Файл:** `movement_recommendations_streamlit.py`

```python
def get_item_importance(self, item_name: str, ads_value: float) -> str:
    """Определение важности товара на основе ADS и других факторов"""
    
    if ads_value <= 0:
        return 'медленный'
    
    # Получаем квантили ADS для определения важности
    if hasattr(self.system, 'calculated_ads') and self.system.calculated_ads is not None:
        ads_data = self.system.calculated_ads['ads']
        
        # Рассчитываем квантили
        q90 = ads_data.quantile(0.9)  # 90-й перцентиль
        q75 = ads_data.quantile(0.75) # 75-й перцентиль
        q25 = ads_data.quantile(0.25) # 25-й перцентиль
        
        if ads_value >= q90:
            return 'критичный'    # Топ 10% товаров
        elif ads_value >= q75:
            return 'важный'       # Товары с 75-90% ADS
        elif ads_value >= q25:
            return 'обычный'      # Товары с 25-75% ADS
        else:
            return 'медленный'    # Нижние 25% товаров
```

### Формула важности:
- **Критичный**: ADS ≥ Q90 (топ 10% по продажам)
- **Важный**: Q75 ≤ ADS < Q90 (75-90 перцентили)
- **Обычный**: Q25 ≤ ADS < Q75 (25-75 перцентили)
- **Медленный**: ADS < Q25 или ADS = 0 (нижние 25%)

## 📈 6. Расчет MIN/MAX запасов

### Базовая формула

**Файл:** `modular_inventory_system.py` (строки 1321-1375)

```python
def calculate_min_stock(self, ip_target_days: int = None, min_stock_days: int = None) -> Dict:
    
    # Параметры по умолчанию
    ip_days = ip_target_days or self.default_params['ip_target_days']    # 7 дней
    stock_days = min_stock_days or self.default_params['min_stock_days'] # 30 дней
    
    # Формулы расчета минимальных запасов:
    
    # 1. Транзитное потребление = ADS × транзитное время
    df['transit_consumption'] = df['ads'] * ip_days
    
    # 2. Базовый минимальный запас = ADS × дни запаса  
    df['min_stock_base'] = df['ads'] * stock_days
    
    # 3. Итоговый минимальный запас = базовый запас + транзитное потребление
    df['min_stock_total'] = df['min_stock_base'] + df['transit_consumption']
```

### Итоговая формула:
```
MIN_STOCK = ADS × min_days × importance_boost × multiplier
MAX_STOCK = ADS × max_days × importance_multiplier × multiplier
```

```python
def calculate_max_stock_for_system(self, system) -> Dict:
    
    # Настройки по типам точек:
    default_settings = {
        'хабы': {'min_days': 30, 'max_days': 90},
        'склады': {'min_days': 20, 'max_days': 60}, 
        'магазины': {'min_days': 10, 'max_days': 25}
    }
    
    # Формулы для каждого типа точки:
    for point_type, settings in self.default_settings.items():
        min_days = settings['min_days']
        max_days = settings['max_days']
        
        # MIN запас = ADS × минимальные дни
        df[f'{point_type}_min_stock'] = df['ads'] * min_days
        
        # MAX запас = ADS × максимальные дни
        df[f'{point_type}_max_stock'] = df['ads'] * max_days
        
        # Диапазон = MAX - MIN
        df[f'{point_type}_range'] = df[f'{point_type}_max_stock'] - df[f'{point_type}_min_stock']
```

```python
def determine_status(current_stock, min_stock, max_stock, ads_value):
    status = 'good'
    if ads_value > 0:
        if current_stock < min_stock:
            if current_stock < min_stock * 0.3:  # меньше 30% от MIN
                status = 'critical'
                urgency = int((min_stock - current_stock) / min_stock * 100)
            elif current_stock < min_stock * 0.7:  # меньше 70% от MIN
                status = 'warning'
            else:
                status = 'low'           # меньше MIN но не критично
        elif current_stock > max_stock:
            status = 'excess'            # избыток товара
        else:
            status = 'good'             # норма (между MIN и MAX)
    elif current_stock > 0:
        status = 'no_ads_stock'         # есть остатки, но нет продаж
    else:
        status = 'no_ads'               # нет ни продаж, ни остатков
    
    return status
```

### Статусы товаров:
- **'critical'**: остаток < 30% от MIN (при ADS > 0.5)
- **'warning'**: остаток < 70% от MIN
- **'low'**: остаток < MIN
- **'good'**: MIN ≤ остаток ≤ MAX
- **'excess'**: остаток > MAX
- **'no_ads'**: нет продаж
- **'no_ads_stock'**: есть остатки, но нет продаж
