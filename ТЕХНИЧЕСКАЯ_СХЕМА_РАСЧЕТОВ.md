## 📊 КЛЮЧЕВЫЕ ФОРМУЛЫ

### 1. Основные расчеты:
```
ADS = Продажи_за_период / Количество_дней
Норма_запаса = ADS × Дни_запаса
Оборачиваемость = (Остаток × 30) / Продажи_за_месяц
```

### 2. ABC анализ:
```
A группа: 80% от общей выручки
B группа: следующие 15% (80-95%)
C группа: оставшиеся 5% (95-100%)
```

### 3. Приоритеты перемещений:
```
Высокий: разница_ADS > 1000 ИЛИ критический_дефицит
Средний: 500 < разница_ADS ≤ 1000
Низкий: разница_ADS ≤ 500
```

## 🎯 МАТРИЦА РЕШЕНИЙ

### Логика рекомендаций:
```
                   │ ADS > 100  │ ADS 10-100 │ ADS < 10
───────────────────┼────────────┼────────────┼──────────
Остаток < 7 дней   │ КРИТИЧНО   │ ВАЖНО      │ НИЗКИЙ
Остаток 7-30 дней  │ ХОРОШО     │ НОРМА      │ ИЗБЫТОК  
Остаток > 30 дней  │ ИЗБЫТОК    │ ИЗБЫТОК    │ МЕРТВЫЙ
```

### Цветовые коды:
- 🔴 **КРИТИЧНО**: Немедленное пополнение
- 🟡 **ВАЖНО**: Планировать пополнение
- 🟢 **ХОРОШО/НОРМА**: Текущий уровень оптимален
- 🟠 **ИЗБЫТОК**: Рассмотреть перемещение
- ⚫ **МЕРТВЫЙ**: Списание/распродажа
